# ニコニコ動画風コメントアドオン

Slidevでニコニコ動画のようなコメントを流すことができます！

<br>

### 使い方

- **W**: コメント表示のON/OFF
- **C**: 手動でコメントを入力

---

# デモページ1

このスライドには自動でコメントが流れます

<v-clicks>

- コメントは右から左へ流れます
- 色やサイズを指定できます
- 複数のレーンで表示されます

</v-clicks>

---

# デモページ2

## 機能一覧

1. **自動コメント**: JSONファイルから読み込み
2. **手動コメント**: Cキーで入力
3. **カスタマイズ**: 速度、色、サイズなど
4. **制御**: Wキーで切り替え

---

# デモページ3

### 設定例

```yaml
niconico:
  enabled: true # 有効/無効
  speed: 5000 # 流れる速度（ミリ秒）
  maxLanes: 10 # 最大レーン数
  comments: "./comments.json" # コメントファイル
```
